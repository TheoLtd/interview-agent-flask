# 增强版面试系统 API 文档

## 🎯 **概述**

本文档描述了参考 `langgraph-AI-interview-agent` 项目优化后的面试系统 API 接口。新版本提供了更专业、更全面的面试分析和简历优化功能。

## 🔄 **主要改进**

### 1. **多维度评估体系**

- **技术基础知识**: 深度评估技术概念理解和实践经验
- **岗位匹配度**: 分析技能与岗位要求的契合度
- **语言表达**: 评估沟通能力和专业术语使用
- **逻辑思维**: 考察问题分析和解决方案的逻辑性
- **创新能力**: 评估创新思维和技术前瞻性
- **抗压能力**: 结合表情分析的压力管理评估

### 2. **情绪分析集成**

- 实时表情检测数据分析
- 情绪稳定性评分
- 压力反应评估
- 个性化情绪管理建议

### 3. **个性化建议系统**

- 基于专业背景的职业发展建议
- 技术能力提升建议
- 面试技巧改进建议
- 情绪管理训练建议

### 2. 智能反馈展示

**接口**: `GET /interview/feedback2`

**描述**: 优先返回最新的增强版分析结果，支持多种格式降级

**响应类型**:

- `enhanced`: 增强版分析结果
- `simple_json`: 简单 JSON 格式反馈
- `simple_text`: 文本格式反馈
- `fallback`: 降级默认内容

### 3. 专用增强分析

**接口**: `GET /interview/feedback/enhanced`

**描述**: 专门的增强版反馈接口，实时生成分析报告

## 🎭 **表情分析集成**

### 表情检测数据结构

```json
{
  "emotion_distribution": [2, 1, 12, 0, 2, 5, 1, 22],
  "emotion_labels": [
    "其他(非人脸表情图片)",
    "其他表情",
    "喜悦",
    "愤怒",
    "悲伤",
    "惊恐",
    "厌恶",
    "中性"
  ],
  "emotion_percentages": {
    "喜悦": 26.7,
    "中性": 48.9,
    "惊恐": 11.1,
    "其他": 13.3
  },
  "emotional_stability_score": 78
}
```

### 情绪稳定性评分算法

```
基础分数: 70分
积极情绪加分: 喜悦×1.0 + 中性×0.8
消极情绪扣分: 愤怒×1.0 + 悲伤×0.8 + 惊恐×0.6 + 厌恶×0.7
最终得分: 基础分数 + (积极情绪 + 消极情绪) × 0.3
取值范围: 0-100分
```

## 🛠️ **技术特性**

### 1. **降级策略**

- 增强分析失败时自动降级到简单分析
- 简单分析失败时提供默认反馈内容
- 确保 API 的高可用性

### 2. **数据持久化**

- 自动保存分析结果到本地文件
- 支持 JSON 和文本格式
- 便于后续数据分析和用户查询

### 3. **错误处理**

- 详细的错误信息和建议
- 异常情况的优雅处理
- 调试信息的完整记录

### 4. **性能优化**

- 异步处理大文件上传
- 内存优化的文档解析
- 缓存机制减少重复计算

## 📊 **评分体系**

### 面试评分维度 (0-100 分)

| 维度         | 权重 | 评分标准                                   |
| ------------ | ---- | ------------------------------------------ |
| 技术基础知识 | 25%  | 概念理解、实践经验、技术广度、学习能力     |
| 岗位匹配度   | 20%  | 技能匹配、经验相关性、成长潜力、文化适应   |
| 语言表达     | 15%  | 表达清晰度、结构化思维、专业术语、互动能力 |
| 逻辑思维     | 20%  | 问题分析、解决方案、因果关系、批判性思维   |
| 创新能力     | 10%  | 创新思维、技术前瞻、优化意识、学习探索     |
| 抗压能力     | 10%  | 压力处理、问题适应、情绪控制、韧性表现     |

### 简历评分维度 (0-100 分)

| 维度       | 权重 | 评分标准                         |
| ---------- | ---- | -------------------------------- |
| 结构格式   | 20%  | 版面设计、信息层次、格式一致性   |
| 内容完整性 | 25%  | 信息完整度、经历覆盖面、技能展示 |
| 专业匹配度 | 25%  | 经历匹配度、技能相关性、发展路径 |

## 🚀 **使用建议**

### 1. **最佳实践**

- 确保面试对话内容充分 (至少 3 轮以上问答)
- 启用表情检测功能获得更全面的分析
- 定期清理生成的分析文件避免存储占用

### 2. **API 调用顺序**

```
1. POST /interview/init (初始化面试)
2. POST /interview/image_detect (表情检测, 多次调用)
3. GET /interview/answer (面试对话, 多次调用)
4. GET /interview/feedback (生成反馈)
5. GET /interview/feedback2 (展示反馈)
```

### 3. **错误处理**

- 检查响应中的 `success` 字段
- 根据 `type` 字段判断返回内容格式
- 实现适当的重试机制
